# DDRevoke — 钉钉 macOS 消息防撤回与自动标记插件

DDRevoke 是一款专为 macOS 版钉钉打造的增强插件，旨在提供无感、原生、纯净的消息保留与防撤回体验。

## 🌟 功能亮点

1. **消息智能防撤回**：
   - **拦截他人撤回**：自动保留对方尝试撤回的所有文字、图片、文件、语音及卡片消息，聊天气泡与会话列表均完整保留。
   - **自身撤回放行**：本人主动撤回的消息正常放行撤回，保持个人操作习惯不受影响。
2. **自动贴表情标记**：
   - 拦截到撤回消息时，自动在原消息气泡下方添加表情标记（默认 🤔 思考，支持自定义切换），清晰标记该消息曾被撤回。
3. **原生设置入口与快捷键**：
   - 深度集成于钉钉顶部菜单栏【🛡️ 防撤回】菜单；
   - 支持全局快捷键 `⌘\` 随时唤出原生设置面板，自由调节防撤回总开关、标记表情、提示音及系统通知。
4. **系统通知横幅与提示音**：
   - 拦截到撤回时，系统右上角弹出横幅通知并伴有声音，清晰显示撤回人姓名。
5. **权限永久保留机制 (TCC Permission Preservation)**：
   - 彻底解决插件覆盖安装或升级后麦克风、摄像头、通知等权限失效的问题；
   - 升级过程中不修改主程序代码签名，原有系统授权永久有效，告别频繁弹窗。
6. **在线检查更新与一键热升级**：
   - 原生菜单与设置面板内支持一键【🔄 检查更新...】；
   - 钉钉启动后自动检测最新版本，发现新版一键热更新秒级生效，无需重新下载安装包。
7. **纯净无感运行**：
   - 无任何多余后台程序常驻，平时直接正常打开系统“钉钉”图标即可。

## 📦 安装与使用

### 安装步骤
1. 前往 [Releases](https://github.com/kts-kris/DDrevoke/releases) 页面下载最新的 `DDRevoke_v1.0.3.dmg`；
2. 打开 DMG 镜像，双击运行 **【一键安装 (双击运行).command】**；
3. 按照提示完成安装（约 2 秒），完成后即可退出并推出 DMG；
4. 像往常一样直接打开系统的【钉钉】即可正常使用。

### 配置方式
- 启动钉钉后，顶部菜单栏可见【🛡️ 防撤回】菜单；
- 随时按快捷键 `⌘\` 呼出设置面板，可自由开关各项功能与切换标记表情。

### 在线更新
- 在顶部【🛡️ 防撤回】菜单中点击【🔄 检查更新...】；
- 检测到新版后点击“立即热更新”，插件将自动下载并更新，提示重启钉钉后即刻生效。

### 卸载方法
- 若需要完全恢复为官方原始钉钉，打开 DMG 双击运行 **【一键卸载 (双击运行).command】**，秒级完全还原。
